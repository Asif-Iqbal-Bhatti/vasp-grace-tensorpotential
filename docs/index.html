GRACE machine-learning potentials for VASP users

Run your VASP inputs on a machine-learning potential

vasp-grace reads POSCAR and INCAR, computes energies, forces and stresses with a GRACE model, and writes VASP-format output. Ten command-line tools build on it for defects, ion transport and topological phonons.

Get started View on GitHub

How it works

Same files in, same files out

  1. Keep your inputs

    Use an existing INCAR. Add one tag, GRACE_MODEL; tags vasp-grace does not use are ignored.

  2. Run vasp-grace

    IBRION and ISIF choose the task: single point, relaxation, molecular dynamics, phonons or the elastic tensor.

  3. Read the usual output

    OUTCAR, OSZICAR, CONTCAR and XDATCAR are written as VASP writes them, so your scripts keep working.

# INCAR: phonons and elastic constants
GRACE_MODEL = GRACE-2L-OAM
IBRION = 6
ISIF   = 3
LPHON_DISPERSION = .TRUE.

Tools

What you can compute

Each tool is a command installed with the package. Run any of them with --help for options.

Structure and uncertainty

  • vasp-graceVASP drop-in: relaxation, MD, phonons, elastic constants
  • grace-active-learningFlags structures the model has not seen, for DFT labelling
  • grace-mcMetropolis Monte Carlo with displacement and swap moves
  • grace-dislocationEdge, screw and mixed dislocations, isotropic or anisotropic

Ion dynamics and transport

  • grace-lihoppingIon hop detection, hop networks and activation energies
  • grace-kappaLattice thermal conductivity by reverse non-equilibrium MD

Topology and condensed matter

  • grace-topo-phononsWeyl and Dirac phonon crossings with their Berry phase
  • grace-phonon-berryPhonon Zak phases, Berry curvature and Chern numbers
  • grace-topologyPersistent-homology fingerprints of crystal and defect structures
  • grace-moireCommensurate twisted bilayers and their stacking maps

Models

Any GRACE model, with built-in uncertainty

Choose a model

Every tool accepts any GRACE foundation model (the 1L, 2L and 3L families) or a path to your own fine-tuned model. GRACE-2L-OAM is the default. grace_models list shows what is available.

Know when to trust it

Newer GRACE models report a per-atom extrapolation grade, γ. Above 1, the model is outside its training data. grace-active-learning --calm uses this to pick structures for DFT from a single model.

Scope

What a potential can tell you

In reach

  • Structures, phonons and elastic constants
  • Diffusion and thermal transport
  • Defects, grain boundaries, twisted bilayers
  • Topology of phonon bands

Needs DFT

  • Electronic bands and their topology
  • Electron–phonon coupling and Tc
  • Magnetism

Get started

Install and try it

git clone https://github.com/Asif-Iqbal-Bhatti/vasp-grace-tensorpotential
pip install -e ".[examples]"
marimo edit examples/quickstart.py

The example notebook relaxes a crystal, fits its equation of state and explores the analysis tools. The README has the full INCAR reference, every option and the roadmap.
